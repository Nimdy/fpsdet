# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in issues, pull requests, and every other project space.

One rule specific to this repo: do not name or accuse a real player. Use made-up ids in every report and sample.

## Reporting

To report a conduct problem privately, use GitHub's private reporting: the **Security** tab, then **Report a vulnerability**. Start the title with "Conduct". It is the project's only private channel, and only the maintainer can read it.

If it can be public, open an issue addressed to the maintainer.

The maintainer handles reports and enforcement as the Covenant describes.
